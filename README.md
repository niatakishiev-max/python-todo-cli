# Python ToDo CLI

Консольный ToDo-менеджер на Python.

Проект сделан как учебное CLI-приложение: пользователь управляет задачами через терминал, а данные сохраняются в JSON-файл.

## Возможности

- Добавление задач
- Просмотр активных задач
- Удаление задач
- Отметка задачи выполненной
- Просмотр выполненных задач
- Возврат выполненной задачи в активные
- Напоминания по дате и времени
- Проверка неправильного ввода номера задачи
- Защита от пустого названия задачи
- Сохранение данных в `tasks.json`

## Напоминания

При добавлении задачи можно указать напоминание в формате:

```text
ГГГГ-ММ-ДД ЧЧ:ММ
```

Пример:

```text
2026-06-05 18:30
```

Если время напоминания уже наступило, программа покажет сообщение при запуске. После этого напоминание очищается, чтобы не повторяться при каждом запуске.

Важно: это консольная программа. Она проверяет напоминания только тогда, когда запущена.

## Запуск

```bash
python todo_list.py
```

## Структура данных

Данные хранятся в файле `tasks.json` рядом с `todo_list.py`.

Пример структуры:

```json
{
    "tasks": [
        {
            "title": "Купить хлеб",
            "done": false,
            "reminder": "2026-06-05 18:30",
            "reminded": false
        }
    ],
    "completed_tasks": []
}
```
